# Overview
This is an updated portfolio to showcase my projects in a more intuitive and flexible environment. This portfolio is also the test implementation for the Mattkleyn Component Library to ensure the components work as intended and are in no way restrictive to building complex sites.

# Architecture
Currently in Post MVP phase, with the site being deployed.

This portfolio is a client-side, Vite React SPA that utilizes a component-library/design system repo that I have been building alongside the portfolio. 

This portfolio becomes the component library demo additionally with the following aspects:
- React router navigation layer,
- JSON-based CMS layer,
- Hosting agnostic deployment,
- Future-ready serverless backend integration

# Installation and usage
This is obviously not intended to be installed and used by someone else. However if you are just intending to play around with the code to understand React or the Mattkleyn Component library better, then go ahead.
